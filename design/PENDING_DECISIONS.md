# Decisions waiting to be written into GAME_DESIGN.md

*Made in conversation on 2026-10-08, after "Decisions made" 1-20. They will be applied to the design doc in one pass once this round of talk is done. Until then, they override the doc.*

- **21. Every line of original English is the creator's.** "I also want to personally decide on every single bit of English text that appears in the game that is original... including UI menus everything." All strings live in one text system with ids; each is a draft until approved; release builds ship approved text only. Not ours: real place names and the verbatim public-domain quotes (still vetoable).
- **22. No book framing, no crutches.** "I feel like leaning hard into the book theme isn't a great direction. I want this game to be great on its own merits. Like swords and sworcery... It's 1000 heroz it's suica game it's kings quest it's Oregon trail but it's also entirely its own blend." Remove the bookshelf, books, chapters, pages, volumes, back cover, "picture-book", the storybook narrator frame and the "Storybook" mode name. The art, engine, permadeath, odds, park, Larry moments and Trail Register stay. Session 1's title-page text batch is on hold until the new framing is set.
- **23. Ways to play.** An open mode to plan any hike, and a **Hike of the Day**: the same route for everyone each day, with a time leaderboard. Each big route can also have an **FKT** ("I love trail running and FKT culture. Each big route in the game could also have a fkt").
- **24. Hike of the Day is one shot.** "One shot I love it." One attempt per day; the score is the time, alive (a death is a DNF).
